# LaTeX templates

Both examples use fictional details. The app generates these layouts from your own confirmed profile; choose Spiral or Classic in Profile. An optional original `.tex` CV keeps its factual content and row structure; Spiral restyles it to match the letter. Classic preserves its original layout. Tectonic compiles with untrusted mode.

The black-and-white design uses a subtle dot field behind the text, a bold personal name and matching credentials. Document headers have no app name or document-type label. The default stays concise and changes only the short profile; it does not rewrite your factual CV entries. The optional source and demo footer credits the workflow creator, Edis Tireli, independently of the applicant name. Black pages look best on screen; choose Classic for printing.
